# Photo Slides

Adobe Premiere Pro плагині: таймлайндағы фотолардан бір батырмамен слайдшоу жасайды
(ақ жиекті фото, бұлыңғыр фон, ақ жарқылмен ауысу, кезектескен қозғалыс).

## Орнату
1. **Code → Download ZIP** басып, архивті ашыңыз.
2. Mac: `Install (Mac).command` файлын оң жақ батырмамен басып, Open таңдаңыз.
   Windows: `Install (Windows).bat` файлын екі рет басыңыз.
3. Premiere Pro-ны қайта ашыңыз: **Window → Extensions → Photo Slides**.

Premiere Pro 2020 және одан жаңа нұсқалар. Плагин жаңартуларды өзі тексеріп, өзі орнатады.

## Қолдану
Фотоларды таймлайнға қойып, `I` және `O` арқылы аралықты белгілеңіз де, «Слайдшоу жасау» басыңыз.
